# Project 2 contribution

## Proposition

**Abortion clinic access improved in the United States from 2017 to 2020.**

A proposition is one debatable statement. One visualization should make the statement look convincing, while the other should make the opposite conclusion look convincing using the same dataset.

## Supporting visualization

The supporting chart focuses on the 15 states where the number of abortion clinics increased. Together, those states gained 42 clinics. Showing only the states with increases makes the improvement look widespread, even though states with no change or a decrease are left out.

Design choices:

1. I filtered the data to states that gained clinics. This is selective because most of the country is left out (-1.5).
2. I sorted the bars so the largest increases are easy to notice. This uses position and length clearly (+1.5).
3. I used green because it suggests growth and improvement. This changes the mood without changing the values (0).
4. I placed the total gain in the subtitle so the positive result is seen before the limitation (-0.5).

## Opposing visualization

The opposing chart combines every state and compares the 42 clinics gained with the 47 clinics lost. After including states on both sides, the national total decreased by five clinics. Nineteen states lost clinics, 15 gained clinics, and 17 had no change.

Design choices:

1. I aggregated gains and losses so the national result is easy to compare. Every state is included (+1.5).
2. I used red for losses and a darker red for the negative net change. This directs attention to decline but matches the data (0).
3. I included a zero line and a shared scale so positive and negative changes are clear (+2).
4. The title states the negative conclusion directly. The claim is supported, but its framing is one-sided (-0.5).

## Which side I lean toward

I lean against the proposition. The supporting chart shows real growth in some states, but it leaves out every state that stayed the same or lost clinics. When all states are included, the country had five fewer clinics overall, and more states lost clinics than gained them. Clinic count is only a rough measure of access because the dataset does not show travel distance, appointment availability, or the number of patients each clinic can serve.

Source: Guttmacher Institute Abortion Data by State, course-provided dataset.
